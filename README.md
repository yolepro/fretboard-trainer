# FretStudio

Application web et mobile (Expo / React Native, TypeScript) pour maîtriser le manche de la guitare :
gammes, positions, exercices de doigté avec partition et tablature synchronisées, entraînement de l'oreille.

L'application est entièrement locale : pas de serveur ni de base de données. Les réglages et les records
sont enregistrés sur l'appareil.

- `frontend/` : l'application (expo-router, écrans dans `app/(tabs)/`, logique musicale dans `src/music/`,
  audio dans `src/audio/`).
- `LANCER.md` : comment lancer l'application sur le Mac et sur un téléphone.
